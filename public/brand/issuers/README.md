# Issuer logos

The five issuers whose tokens Vestail resolves. Each file is that issuer's own
logo, taken from their own site on 2026-09-23:

| File | Source |
| --- | --- |
| `xstocks.svg` | the header lockup on <https://xstocks.com> |
| `ondo.svg` | `ondo.finance/images/nebula-footer-wordmark.svg` |
| `backpack.svg` | the header mark and wordmark on <https://backpack.exchange>, locked up side by side |
| `tessera.svg` | the header logo on <https://www.tessera.pe> |
| `prestocks.svg` | `prestocks.com/ui/brand-logos/prestocks-logo.svg` |

Two changes were made, and only these two: every colour was replaced with
white, because the strip sits on the site's dark gradient and five different
brand palettes side by side would read as noise rather than as a row; and the
`width`/`height` attributes were dropped so each one can be sized in CSS.
No artwork was redrawn, recomposed or restyled otherwise — the Backpack file
places that company's own two assets in a row, at their own proportions.

These logos are the trademarks of their respective owners. They appear here to
name the issuers Vestail checks, which is nominative use; nothing here implies
endorsement, partnership, or that any of them have reviewed Vestail.
